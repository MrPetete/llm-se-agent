## 技术决策

| 决策事项 | 选择 | 理由 |
|----------|------|------|
| 文档格式 | Markdown（.md） | 可纳入版本控制，GitHub 可直接预览，所有技术水平的成员均可使用 |
| 报告模板格式 | .docx（Word） | 符合课程提交要求，具备结构化排版 |
| 风格指南存放位置 | 仓库中的 `docs/style_guide.md` | 单一可信来源，与代码同步进行版本管理 |
| 章节责任制模型 | 按成员划分章节存根 | 各成员填写自己的章节，M6 负责审阅并统一文风 |
| 集成参考文档 | 单一 `docs/integration_reference.md` | 避免组员在多份报告中查找接口细节 |
| 测试场景来源 | M7 的 `QA_Scenarios_v1.xlsx` | 单一主文件，M6 引用但不重复复制 |
